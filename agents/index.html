Attribution des missions : chaque commit est rattaché à un agent par mots-clés de domaine, sauf les commits « Queue: <agent> start » qui portent l'agent en clair. C'est une heuristique — un commit qui touche deux domaines est compté une seule fois, pour le premier qui matche. 18 commits non attribuables sont exclus.

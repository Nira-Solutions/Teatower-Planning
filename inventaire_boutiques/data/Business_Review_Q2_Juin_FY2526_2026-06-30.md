## Limites et caveats de cette analyse

1. **Categorisation canal incomplete (46 % "Autre")** : les chiffres par canal GMS/Horeca/Revendeur/D2C sont sous-estimes. La vraie ventilation necessiterait un tagging complet des partenaires.
2. **Cout standard manquant sur ~20 produits** dont GI0820 (11 564 EUR CA Q2) : la marge brute de 70,5 % est probablement surestimee de 2-4 pts.
3. **Comparaison YoY Q2 N-1 non fiable par canal** : le perimetre de categorisation N-1 est trop different pour des comparaisons canal a canal. Seul le total (492k N-1 vs 324k) est comparable -- et il inclut des risques d'anomalies d'exercice N-1.
4. **Faux gains POS (compte 757100)** : ces ecritures (identifiees dans la memoire comptable -- ~100k EUR cumules FY) n'impactent pas les out_invoice lus ici. Le CA commercial presente est isole de ces anomalies.
5. **Boutiques TT (POS)** : les ventes POS boutiques (Namur, Waterloo, Liege, Rocourt) transitent par des journaux specifiques. Leur CA FY25-26 est de 33 155 EUR via ces journaux. Ils sont classes "Autre" dans la ventilation canal (pas de categorie "Magasins" active sur ces partenaires).
6. **Amazon FBA** : aucune donnee Amazon disponible dans Odoo ou dans le dossier data/. CA Amazon FY non quantifiable.
7. **Shopify cross-check** : non realise (pas de fichier export fourni). Les chiffres D2C Shopify proviennent uniquement d'Odoo -- a croiser avec le dashboard Shopify pour validation.
